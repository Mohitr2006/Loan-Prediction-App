About This Project

This is an end-to-end Loan Approval Prediction web application built using Machine Learning and Flask. It predicts whether a loan application is likely to be approved or rejected based on applicant information such as income, CIBIL score, loan amount, employment status, and asset values.

How It Works

  • Users enter loan applicant details through a responsive web interface.
  • Flask receives the form data and converts it into a pandas DataFrame.
  • A preprocessing pipeline performs scaling and one-hot encoding.
  • The processed data is passed to a trained Random Forest model.
  • The model predicts whether the loan will be Approved or Rejected.

Tools Used

Python Flask Scikit-Learn Pandas NumPy HTML CSS Joblib
